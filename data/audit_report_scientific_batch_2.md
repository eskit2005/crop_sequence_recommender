* The fallback to `Fallow - Fallow - Fallow` ($K=1$) in Manda (`loc_11`, ML) is a known edge-case bug where missing suitability rows in the BARC CZIS matrix cause an unintended drop into dummy placeholders.
* **Recommended Fix**: Implement a fallback heuristic that interpolates crop suitability from adjacent upazilas in the same AEZ (e.g., Mohadevpur or Badalgachhi in AEZ-5) whenever an upazila-land type query returns zero suitable crops.
